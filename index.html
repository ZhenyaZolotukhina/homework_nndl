1) Data Load & Inspection

After loading, you will see: a preview table, dataset shape, missing %, and quick EDA bars (Survival by Sex/Pclass).
Tip: If you deploy on GitHub Pages, Fetch from repo is simplest. Locally, use file inputs.

2) Preprocessing

Impute: Age=median, Embarked=mode. Standardize Age/Fare. One-hot: Sex/Pclass/Embarked. Optional engineered: FamilySize/IsAlone. This section prints final feature list and tensor shapes.

3) Model

Shallow binary classifier: Dense(16, relu) → Dense(1, sigmoid). Optimizer: Adam. Loss: binaryCrossentropy. Metric: accuracy.

4) Training (live)

80/20 stratified split by Survived. Early stopping on val_loss (patience=5). Live loss/accuracy plots appear below.

5) Metrics

We compute ROC curve + AUC on validation probabilities. Threshold slider updates: confusion matrix + Precision/Recall/F1.

6) Prediction & Export

Predict probabilities for test.csv. Download: submission.csv (PassengerId, Survived) using current threshold, and probabilities.csv (PassengerId, probability). Export model via downloads://titanic-tfjs.
Deployment notes: Create a public GitHub repo, commit index.html/app.js/train.csv/test.csv to root, enable Pages (main/root), open your Pages URL.
If Pages shows deployment timeouts, add an empty .nojekyll file in repo root and re-save Pages settings.
